# HV Inspection Dashboard

Dashboard สำหรับผลตรวจเช็คระบบไฟฟ้าแรงสูง 22 kV จาก Sep.pdf

## เปิดใช้งาน
เปิด `dist/index.html` ในเว็บเบราว์เซอร์ หรือให้เว็บเซิร์ฟเวอร์ใช้โฟลเดอร์ `dist` เป็นรากของเว็บไซต์ ไม่ต้องติดตั้ง dependencies

## ข้อมูล
- แบบฟอร์ม 5 หน้า รวม 65 ช่องรายการ
- เลือกช่วงเวลา สถานที่ และจุดตรวจแรงบิดได้
- เปิดต้นฉบับ PDF จากรายละเอียดแต่ละแบบฟอร์มได้
- `dist/data.json` เป็นข้อมูลที่ถอดจากเอกสาร ส่วนหน้าเว็บใช้ข้อมูลที่ฝังใน `dist/index.html` การเปลี่ยน JSON เพียงอย่างเดียวจะไม่อัปเดตหน้าเว็บ

## ข้อจำกัด
วันที่บางหน้าไม่ตรงกับชื่อไฟล์ Sep.pdf และมีลายมือที่ต้องยืนยัน โดยแสดงหมายเหตุไว้ใน Dashboard แล้ว ขีดและช่องว่างไม่นับเป็นผลผ่าน ข้อมูลมีครั้งเดียวต่อสถานที่ จึงยังสรุปแนวโน้มอุปกรณ์เดิมตามเวลาไม่ได้

เอกสารมีข้อมูลภายใน ควรเก็บ repository เป็น Private เว้นแต่ได้รับอนุญาตให้เผยแพร่
